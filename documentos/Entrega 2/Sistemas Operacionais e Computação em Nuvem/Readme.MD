# Sistemas Operacionais e Computação em Nuvem - Entrega 2

A segunda entrega da disciplina **Sistemas Operacionais e Computação em Nuvem** é composta por três elementos:

- Um documento explicando a metodologia utilizada para monitorar uma instância em nuvem. Neste projeto, o monitoramento foi aplicado com foco na base de dados, considerando a grande quantidade de informações que transitam entre as requisições realizadas pelo sistema e o banco de dados.

- Uma estrutura Docker preparada para execução em ambiente de nuvem. Com isso, a aplicação ganha maior portabilidade, organização e facilidade para futuras atualizações ou expansões.

- Um arquivo *COLAB* referente aos algoritimos de IA para monitoramento.
